Negociar precios por volumen de compra, validar segundas fuentes (*second sources*) para el MCU u otros *cost drivers* o simplificar etapas analógicas complejas.

Ratio Diversidad R ¿Qué es? Relación entre números de parte de resistencias únicas ( U resistencias U_{\text{resistencias}} Uresistencias​) y cantidad total física de resistencias ( N total_resistencias N_{\text{total\_resistencias}} Ntotal_resistencias​): R D , R = U resistencias N total_resistencias R_{D, R} = \frac{U_{\text{resistencias}}}{N_{\text{total\_resistencias}}} RD,R​=Ntotal_resistencias​Uresistencias​​ Unicode: R_D,R = U_resistencias / N_total_resistencias. ¿Cómo mejorar? Consolidar valores nominales a la serie estándar E24 o E96. Un ratio R D , R ≤ 0.4 R_{D, R} \le 0.4 RD,R​≤0.4 representa un excelente nivel de estandarización.

Consolidar encapsulados físicos (footprints) y estandarizar valores de capacidad para desacoplos a un único valor (ej. 100nF y 10uF).
